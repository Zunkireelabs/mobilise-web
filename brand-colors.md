## Brand Color Palette

| Name | Hex | Usage |
|---|---|---|
| Primary (brand teal) | `#0A919B` | Main accent — CTAs, links, highlights |
| Primary Dark | `#12474C` | Darker teal variant — used as theme color on some pages |
| Black | `#171717` | Primary text / dark section backgrounds |
| White | `#FFFFFF` | Base background |
| Gray (light) | `#DDDBDD` | Secondary text on dark backgrounds |
| Text Muted | `#7B7E84` | Muted/secondary copy |
